# SeaDesign – версия 1

## Качване в GitHub
1. Разархивирай ZIP файла.
2. В репозиторито SeaDesign избери **Add file → Upload files**.
3. Качи **съдържанието вътре в папката**, не самата папка.
4. Натисни **Commit changes**.

## Пускане чрез GitHub Pages
1. Отвори **Settings → Pages**.
2. При **Build and deployment** избери **Deploy from a branch**.
3. Branch: **main**, Folder: **/(root)**.
4. Натисни **Save**.

След няколко минути GitHub ще покаже публичния адрес.

Това е работеща статична версия. Реални онлайн плащания, автоматично изпращане на поръчки и складови наличности изискват бекенд или WooCommerce.
