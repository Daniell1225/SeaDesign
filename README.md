# SeaDesign

Професионални плажни артикули и сублимация върху текстил.

## Категории

- Premium хавлии (140x70 см, 60% памук / 40% полиестер, 12 €)
- Microfiber хавлии (140x70 см, 100% полиестер, 5 €)
- Детски хавлии
- Пончо
- Спално бельо
- Персонализирани тениски
- Сублимация върху текстил
- Плажни чанти
- Плажни чадъри

Работим с професионални италиански машини – световен лидер в индустриалната сублимация. Това ни позволява да постигнем изключително наситени цветове, висока детайлност и дълготрайност на печата върху текстил.
